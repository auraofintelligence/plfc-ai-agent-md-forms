# PLFC AI Helper Forms

Simple static website for Point Lookout Fishing Club forms that create AI-ready Markdown files.

This repo is only about forms.

A person picks one form, fills a few plain-English boxes, then copies or downloads a `.md` file for an AI tool such as ChatGPT, Claude, Gemini, Copilot, Canva, CapCut, Runway or Suno.

## Forms

- Meetings
- Members and volunteers
- Events
- Social content
- Storage and source notes
- Grants
- Education and visitors

## Local Use

Open `index.html` directly in a browser.

No build step is required.

## Design Notes

- Daylight shoreline palette.
- Full-width hero images.
- One form per job.
- Floating back-to-top button.
- Previous/home/next navigation above the footer.
- Site map in the footer only.
