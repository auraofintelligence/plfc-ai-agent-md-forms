Simple static website for Point Lookout Fishing Club forms that create AI-ready Markdown files.

This repo is only about forms.

A person picks one form, fills a few plain-English boxes, then copies or downloads a `.md` file for an AI tool such as ChatGPT, Claude, Gemini, Copilot, Canva, CapCut, Runway or Suno.

## Public page

- [Open the PLFC AI Helper Forms](https://auraofintelligence.github.io/plfc-ai-agent-md-forms/)

## Forms

- Meetings
- Members and volunteers
- Events
- Social content
- Storage and source notes
- Grants
- Education and visitors

## Local Use

Open `index.html` directly in a browser.

No build step is required.

## Data and review boundary

Form drafts autosave in that browser's `localStorage`. They are not sent to a
club server, but they can remain on the device until the user clears the form
or browser storage. Do not enter private member data, payment details, private
GPS points, unapproved media or confidential Drive paths on a shared device.

The generated Markdown is a handoff for human-reviewed AI work. It does not
verify facts, permissions, cultural safety, grants, official club wording or
publication readiness.

## Design Notes

- Daylight shoreline palette.
- Full-width hero images.
- One form per job.
- Floating back-to-top button.
- Previous/home/next navigation above the footer.
- Site map in the footer only.
