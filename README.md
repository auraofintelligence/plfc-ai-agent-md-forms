# PLFC AI Helper Forms

Plain-English static website for Point Lookout Fishing Club forms that create AI-ready Markdown files.

The site is for committee members, volunteers, club members, locals and visitors who are not technical. A person answers simple questions, downloads a `.md` file, checks it, then uses it with an AI tool such as ChatGPT, Claude, Gemini, Copilot, Canva, CapCut, Runway or Suno.

## What It Covers

- Meetings, agendas, minutes and action lists.
- Membership, volunteers and shared access.
- Fishing events, field ops and public wrap-ups.
- Social content for YouTube Shorts, TikTok, Instagram and Facebook.
- Source files, storage locations and backups.
- Grants, evidence and reporting.
- Privacy, permissions and respectful use of culture, people, images and stories.

## Source Weighting

The older automation documents are treated as historical planning notes.

The current source direction comes from:

- the modern `auraofintelligence/plfc-community-platform` repo
- the 2026 AGM PDF deck
- the current public website at `https://pointlookoutfishingclub.com`
- the public social channel links exposed from the current website

## Local Use

Open `index.html` directly in a browser.

For the form builder, opening the file directly also works. No build step is required.

## Privacy

The form builder runs in the browser. It does not send answers to a server. The downloaded `.md` file is only as safe as what the user chooses to put into it.

People should check every generated file before pasting it into an AI tool.
