# AGENTS.md

Use Australian English.

This repo is a plain static website for Point Lookout Fishing Club AI helper forms. Keep the code easy to read and easy to explain to non-technical committee members.

## Working Style

- Prefer static HTML, CSS and small JavaScript.
- Keep public copy plain, friendly and practical.
- Do not publish private member data, payment details, private Drive paths, private GPS points or unapproved media.
- Treat official club wording, cultural wording, privacy wording, prices and benefits as committee-approval items.
- Avoid public copy that frames the project around one person. Use shared club access, helpers, volunteers and committee language.

## Design Direction

- Daylight shoreline feel: ocean blues, sky blues, white sand, shoreline greens, teal, orange/gold and small purple media accents.
- Use full-width hero images on each page with balanced pale overlays so both image and text remain visible.
- Keep cards at 8px radius or less.
- Include floating back-to-top control and previous/home/next page navigation above the footer.

## Form Direction

- Browser-local forms create `.md` files for AI tools.
- Generated Markdown should include purpose, source files, storage locations, privacy boundaries, review notes and the requested AI output.
- Make the file useful for LLMs, coding agents, super-apps, image models, video models and song/music tools.
- Every generated file must remind the user to check facts, permissions and cultural safety before publishing.
